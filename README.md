# Emotion Recognition System Using Deep Learning

## 📌 Project Description
This project implements a real-time Emotion Recognition System using Deep Learning.  
The system detects human facial expressions and classifies emotions such as Happy, Sad, Angry, Fear, Surprise, Neutral, and Disgust.

A Convolutional Neural Network (CNN) is trained on the FER-2013 facial emotion dataset.  
The model can predict emotions from uploaded images or live webcam input through a simple Streamlit-based user interface.

## 🧠 Technologies Used

- TensorFlow / Keras
- OpenCV
